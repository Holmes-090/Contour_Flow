# Contour Flow sample data

Small, **fictional** datasets for trying Contour Flow. Nothing here is real
site data. Everything is generated by `scripts/make_sample_data.py`.

| File | Content |
|---|---|
| `contour_flow_sample.qgs` | A QGIS project with all three layers loaded (open this first) |
| `contour_flow_sample.gpkg` | `sample_wells` (13 points) and `site_boundary` (1 polygon) |
| `sample_dem.tif` | A 480 × 360 m elevation raster, 2 m cells |

All layers use **EPSG:32633** (WGS 84 / UTM zone 33N), a projected CRS in metres.

### `sample_wells` fields

| Field | Meaning | Pattern |
|---|---|---|
| `well_id` | MW-01 … MW-13 | |
| `gw_elev` | Groundwater elevation (m) | Regional gradient falling to the north-east, with a small recharge mound in the north-west |
| `ground_elev` | Ground surface elevation (m) | A broad hill in the centre-east |
| `bedrock_elev` | Bedrock elevation (m) | Dipping to the north, with a buried channel. **MW-04 has no value** (not drilled to bedrock) |

MW-13 lies **outside** the site boundary on purpose, so you can see the
clipping at work.

## Getting started

Open `contour_flow_sample.qgs` in QGIS (**Project ▸ Open**), then open
Contour Flow from the toolbar or **Plugins ▸ Contour Flow**.

## Test 1: Groundwater contours

| Setting | Value |
|---|---|
| Source | Point layer |
| Point layer | `sample_wells` |
| Value / elevation field | `gw_elev` |
| Clip to polygon | `site_boundary` |
| Interval | Automatic (count 10) |
| Labels | Major only |
| Style | Groundwater |

Click **Generate Contours**.

**Expected:**

- The summary shows 13 usable points, range about 95.6–98.4, and interval 0.25.
- About 10 blue contour lines run north-west to south-east, falling from
  about 98 m in the west to 96 m in the north-east. The whole-metre contours
  (96, 97, 98) are thicker and labelled.
- Nothing is drawn outside the site boundary, so the part of the well field
  around MW-13 is cut off.
- TIN interpolation only covers the area between the outermost wells (their
  convex hull), so the contours stop short of the boundary in places. The
  summary says so.

## Test 2: Ground surface contours

Same as Test 1, but with field **`ground_elev`** and style **Topographic**.

**Expected:** brown contours curving around a hill in the centre-east, a
clearly different pattern from the groundwater contours. The automatic
interval is 0.5, and the whole metres are major contours.

Optional: field `bedrock_elev` with style Neutral gives a third pattern, and
a note that 1 point was skipped (MW-04 has no bedrock value).

## Test 3: DEM contours

| Setting | Value |
|---|---|
| Source | Raster |
| Raster layer | `sample_dem` |
| Interval | Automatic (count 10), or Fixed 0.5 |
| Style | Topographic |

**Expected:** about 13 smooth, closed or edge-to-edge contour lines at 0.5 m
intervals between about 101.5 and 107.5 m, around a hill and a shallow valley.
Optionally clip to `site_boundary` to keep only the site.

## Things to try

- **Advanced settings ▸ Interpolation:** switch to *IDW*, or to *TIN
  Clough–Tocher* for smoother contours, and compare.
- **Advanced settings ▸ Contour lines:** smoothing *Light*, with *Also keep an
  unsmoothed copy* ticked.
- **Output ▸ GeoPackage:** save to a new `.gpkg`. Run twice with the same name,
  and the second layer gets a `_2` suffix instead of overwriting the first.
- Edit a contour layer (toggle editing, move a vertex). Outputs are ordinary
  QGIS layers.

## Regenerating the data

From the repository root:

```bat
scripts\run_with_qgis.bat scripts\make_sample_data.py
```
